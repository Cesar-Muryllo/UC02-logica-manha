# 📚 Estudos de Programação & Lógica

Bem-vindo(a)! Este repositório foi criado com o objetivo de centralizar, organizar e registrar todo o meu processo de aprendizado em programação e fundamentos de lógica.

Aqui você encontrará exercícios de lógica, algoritmos em pseudocódigo, pequenos projetos e testes práticos desenvolvidos ao longo dos meus estudos.

---

## 🎯 Objetivos

- **Domínio da Lógica:** Desenvolver o raciocínio lógico e estruturação de algoritmos.
- **Prática Constante:** Fixar conceitos teóricos através de exercícios práticos.
- **Histórico de Evolução:** Acompanhar minha transição do pseudocódigo para linguagens de programação de mercado.
